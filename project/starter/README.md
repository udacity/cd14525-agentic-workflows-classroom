# Starter Code

This folder contains the starter code for the project. The project has been divided into two parts - phase 1 and phase 2. The same has been done with the starter code. Before starting Phase 2, copy `phase_1/workflow_agents/base_agents.py` into `phase_2/workflow_agents/`. Copy it — do not move it — because you still need it to re-run your Phase 1 test scripts.
